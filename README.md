# philly-parking-app
Proof of concept for a Philadelphia parking app that helps users locate and report available parking spaces.


## Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. The Philadelphia map will appear.

## Operating System

macOS

## Programming Language

JavaScript
